# UniSchedule 2.1 — расписание ФИиИТ

Интерфейс в стиле университетского планера: расписание дня со шкалой времени, выделенное текущее или ближайшее занятие и выбор дней сверху. Изумрудный акцент заменяет синий. Номер пары, подгруппы и аудитории выделены отдельными плашками. Светлая и тёмная темы используют одинаковое расположение элементов. По умолчанию включена тёмная тема; выбор сохраняется в браузере.

## Запуск

Распакуйте архив и откройте `index.html` в современном браузере. Сборка и установка пакетов не нужны. Расписание, шрифты, импорт Excel и экспорт Excel/PDF используют файлы из архива, без внешних CDN.

Для установки как PWA и офлайн-кеширования разместите всю папку на HTTPS-хостинге либо запустите локальный сервер. Например, при установленном Python: `python -m http.server 8000`, затем откройте `http://localhost:8000`. При прямом открытии файла регистрация PWA недоступна, остальные функции работают.

## Управление

- Кнопка солнца/луны в шапке переключает тему.
- Нажмите на курс и группу, чтобы изменить выбор. Изменения применяются после выбора группы.
- Кнопки «1 неделя» и «2 неделя» переключают чередующиеся расписания.
- Дни недели над расписанием переключают выбранный день на компьютере и телефоне. Нижнего блока «Вся неделя» больше нет.
- «Сегодня» возвращает текущий день и автоматически рассчитанную неделю.
- Шестерёнка открывает настройки отсчёта недель.
- «Загрузить Excel» импортирует таблицу ФИиИТ; исходный пример `sample_schedule.xlsx` включён.
- «Экспорт» сохраняет обе недели в Excel или выбранную неделю в PDF с кириллицей.
- На телефоне импорт, экспорт и настройки также доступны через меню.

Исходные данные расписания сохранены из предоставленного приложения. Демонстрационные предметы с изображения в расписание не добавлены. В воскресенье и свободные дни показывается состояние без занятий. Для другого дня или другой недели выделенная карточка показывает первую пару дня, без обратного отсчёта.

## Файлы

`index.html` — разметка; `styles.css` — обе темы и адаптивный интерфейс; `app.js` — данные и логика приложения; `parser.js` — исходный парсер Excel; `sw.js` и `manifest.json` — PWA; `icon.svg` — иконка; `vendor/` — библиотеки; `fonts/` — Golos Text и лицензия SIL Open Font License.

В папке `previews/` находятся реальные скриншоты светлой и тёмной тем на компьютере и телефоне. Версии библиотек: SheetJS 0.18.5, jsPDF 2.5.1, AutoTable 3.8.2; лицензии включены в `vendor/`.

## Режим «На экран Домой» на iPhone

Полупрозрачный режим системной строки состояния заменён обычным (`default`); страница использует `viewport-fit=contain`. Шапка имеет сплошной фон, без размытия и прозрачности. Это исключает предусмотренное прежними настройками наложение статус-бара на шапку. Отрисовка системной области зависит от версии iOS; на реальном iPhone эта версия не проверялась.

Если после обновления опубликованного приложения остаётся старая шапка, закройте приложение полностью и откройте снова. Если iOS сохранила старые параметры ярлыка, удалите только ярлык с домашнего экрана и снова добавьте сайт через Safari. Исходные данные расписания и парсер сохранены.
